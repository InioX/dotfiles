# Useful stuff

This is a list of useful stuff for gaming

## Environment variables

| Variable | Description |
| -------- | ------- |
| `NVPRESENT_ENABLE_SMOOTH_MOTION=1` | Enables frame generation (NVIDIA only) |
| `PROTON_ENABLE_WAYLAND =1` | Enables native wayland |
| `PROTON_ENABLE_NVAPI=1` | Enables stuff like DLSS (NVIDIA only) |
| `__GL_SHADER_DISK_CACHE_SKIP_CLEANUP=1` | Prevents shader cache cleanup |
