# Dotfiles

> **Warning**
> The `config/` folder does not contain all of my dotfiles
> Some need to be generated with [Matugen](https://github.com/InioX/Matugen).

📂 [dotfiles/](./dots/) - All my dotfiles

- 📁 [config/](./config/) - Same as `~/.config/`
- 📁 [templates/](./templates/) - Templates for [Matugen](https://github.com/InioX/Matugen)
- 📁 [scripts/](./local/) - Scripts added to path
- 📁 [local/](./scripts/) - Same as `~/.local/`
- 📁 [desktop-entries/](./desktop-entries/) - Desktop entries
